# Viruthika Portfolio

A responsive React + Vite personal portfolio tailored to a B.Tech CSE student in Quantum Computing & Information Science.

## Run locally

1. Install the current LTS version of [Node.js](https://nodejs.org/).
2. In this folder, run `npm install`.
3. Start the development server with `npm run dev`.
4. Create an optimized production build with `npm run build`.

## Personalize it

All personal content intentionally uses clear `[placeholders]` in `src/App.jsx`. Replace only those items with confirmed information:

- projects, technologies, GitHub and demo links
- university and graduation dates
- current learning focus, achievements, email, LinkedIn, and GitHub

The site is static and has no backend or form submission service. The contact button uses a mailto link after you replace the email placeholder.

## Deploy

After `npm run build`, deploy the generated `dist` folder to Vercel, Netlify, GitHub Pages, or any static hosting provider.
